# Lab 2 — Classification with XGBoost (Ames Housing)

Requirements: [L2_Classification_with_XGBoost.md](L2_Classification_with_XGBoost.md) · Decisions and results: [DOCUMENTATION.md](DOCUMENTATION.md)

## Structure

| File | Purpose |
|---|---|
| `../data/AmesHousing.csv` | Raw dataset, shared by all labs (not in git — place it there manually) |
| `processed_data/` | One cleaned CSV per preprocessing approach (generated by the `01_prep_*` notebooks) |
| `results/` | Cached experiment results and `best_setup.json` (generated by `02`) |
| `common.py` | Shared helpers: data loading, price classes, evaluation and plotting |
| `01_prep_A_baseline.ipynb` | Approach A: drop unneeded columns, fill structural NaNs, ordinal + one-hot encoding |
| `01_prep_B_native_categorical.ipynb` | Approach B: minimal cleaning, XGBoost native categorical support |
| `01_prep_C_feature_engineering.ipynb` | Approach C: approach A + engineered features |
| `02_compare_preprocessing.ipynb` | Compare approaches with fixed hyperparameters across splits and CV; imbalanced classes |
| `03_xgboost_tuning.ipynb` | Manual tuning, Optuna, final evaluation and all plots for the winning approach |
| `04_bonus_lightgbm.ipynb` | Bonus: LightGBM on the same features |

## Run order

1. Run every `01_prep_*` notebook (each writes its CSV to `processed_data/`).
2. Run `02_compare_preprocessing.ipynb` to pick the winning approach.
3. Run `03_xgboost_tuning.ipynb`, then optionally `04_bonus_lightgbm.ipynb`.
